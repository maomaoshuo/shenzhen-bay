# 深圳湾 · 一片被两座城市围住的浅海

一份从岸走到海的深圳湾简明导览：潮间带、红树林、跨海公路大桥、十三公里岸线与对岸的香港，附可拖动的潮位互动剖面和出行信息。

- 预览：https://936arpcp.dola.site/shenzhen-bay/
- 技术栈：单文件静态页面（HTML + CSS + 内联 JS），无构建步骤、无框架依赖
- 字体：Google Fonts（Noto Sans SC / Noto Serif SC），主视觉为自托管 WebP

## 页面结构

| 章节 | 内容 |
| --- | --- |
| 潮间带 | 退潮后的泥滩与底栖生物，从岸到海的观察顺序 |
| 红树林 | 深圳湾红树林的分布与候鸟觅食关系 |
| 潮位 | 可拖动的潮位剖面，随潮高显示淹没范围 |
| 跨海大桥 | 深圳湾公路大桥的走向与观桥位置 |
| 十三公里岸线 | 岸线分段与步行/骑行建议 |
| 对岸 | 湾口两侧的城市关系与跨境视角 |
| 出行信息 | 交通、时间与现场注意事项 |

## 本地预览

```sh
python3 -m http.server 8080
# 打开 http://localhost:8080/
```
